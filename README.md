# F1 Team Dashboard

A prompt-challenge repo for building a Formula 1 team dashboard.

## Challenge brief

Create a polished, data-rich dashboard for an F1 team. The interface should help race engineers and team leadership understand performance across a race weekend, make comparisons quickly, and spot what needs attention.

Use your prompt to define the product direction, audience, visual identity, features, and level of fidelity. Keep the experience coherent, responsive, and easy to scan.

## Getting started

This repository is intentionally ready for your prompt challenge. Add the stack and implementation that best fit the prompt.

## Ideas to explore

- Race weekend overview and session progression
- Driver and constructor performance comparisons
- Strategy, pit stops, tyre stints, and lap pace
- Track conditions, weather, and race control events
- Clear empty, loading, and responsive states

## Data

Use clearly labeled sample data unless a real data source is specified. Do not present mock values as live telemetry.
